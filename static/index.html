The Problem with LLM Judges

Standard benchmarks rely on self-reported agent responses or an "LLM-as-a-judge". Agents easily hallucinate claims like "I refunded ₹2499.00" even when zero backend APIs were ever invoked.

The 3 Deterministic Pillars

1. ToolGateway (The Camera)
Intercepts every single tool call in real-time. Logs sequential parameters, timestamps, and return values into an immutable trace.
2. SupportEnvironment (State)
Mock database state machine enforcing business rules and strict multi-tenant customer isolation boundaries.
3. OutcomeEvaluator (Referee)
Never trusts agent words. Directly checks real state mutations AND validates required execution protocol rules.

Fair Comparison Guarantees

Both Plain Gemini and LangGraph share identical tool schemas, same model checkpoint, same 0.0 temperature, and identical 8-step limits.
